# Roblox-Erfolgsspiel – Handbuch (PDF)

`Roblox-Erfolgsspiel-Handbuch.pdf` ist das Schritt-für-Schritt-Handbuch (Konto → Studio → Starter-Kit → Bauen → Testen → Launch → Live-Ops → Geld).

Neu bauen (Python 3, `reportlab`, Schriften Carlito + DejaVu):

```bash
python3 docs/handbuch/src/build.py
```

- `src/lib.py` Layout, `src/diagrams.py` Abbildungen (selbst gezeichnete Skizzen, **keine** Original-Screenshots),
  `src/ch*.py` / `front.py` / `appendix.py` Inhalte. Der Code in Anhang A wird direkt aus `game/src/` gelesen.
- Alle ⚠-Fakten sind unbestätigt (Creator Hub war bei der Recherche nicht erreichbar) – siehe Kapitel 9.8.
